# Datalisting Aula

Plataforma educativa accesible orientada a adultos mayores.

## Arquitectura inicial
- Frontend del aula separado de la tienda.
- Backend Laravel para autenticación, roles, cursos, inscripciones y progreso.
- Roles: Administrador, Docente y Alumno.
- Material educativo protegido fuera del repositorio público.
- Visor controlado para documentos y videos.
- Diseño de alta legibilidad, navegación simple y ayuda visible.

Estado: estructura inicial en construcción.
