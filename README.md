# Aulas Datalisting

Interfaz para alumnos y administradores con datos privados en Datalisting. Requiere el backend 2026.10.17-integrada.4.

- Aula de muestra: raíz, organización `demostracion`.
- A Remarla: `/a-remarla/`, organización `a-remarla`.
- Dueño: cursos, clases, archivos privados o enlaces, cuentas de alumnos e inscripciones y ubicación del pronóstico.
- Alumno: sus cursos habilitados, clases, materiales, avance, evaluaciones y certificados cuando corresponda.

Las cuentas y los permisos se administran en Datalisting. No hay contraseñas ni claves privadas en GitHub. Una contraseña temporal se cambia primero desde el acceso de Datalisting. Matriz puede entrar a las organizaciones preparadas con su cuenta existente.

El pronóstico del aula autenticada se consulta al backend: MET Norway, con caché y atribución CC BY 4.0. INA, SHN, SMN y NOAA aparecen como enlaces oficiales; todavía no se integran sus niveles de río, mareas o alertas. El pronóstico no sustituye una evaluación de seguridad para navegar. La maqueta anterior queda como referencia y usa su proveedor original Open-Meteo.

La marca de agua y el desenfoque acompañan el control de acceso; los contenidos que un usuario autorizado visualiza pueden ser copiados o capturados. Los archivos permanecen privados y el servidor verifica permisos en cada consulta.
